当前例子：房屋面积 → 房价

提供例子。每条样本是一个输入，外加一个用来判对错的信号。程序对世界的全部了解都来自这里，数据里没有的规律它学不出来。

输入
现实世界里被记录下来的东西
输出
一张数字表：每行一条样本，每列一个特征
在三个例子里分别是什么
  • 房屋面积 → 房价·8 套已成交的房子。输入是面积（平方米），要预测的是成交价（万元）。这 8 条就是训练集。
  • 图片 → 猫 / 狗·真实任务里是 12 张人工标好「猫」或「狗」的图片，输入是像素。这个演示用的是两簇造出来的二维点，代表「每张图被压成 2 个数」之后的样子，这样一页纸就能看完整个过程。
  • 机器人观测 → 动作·机器人按当前策略自己跑出来的 32 段交互。输入是观测（物体在左 / 正前方 / 右），信号是这一步拿到的奖励。没有人告诉它正确动作是什么。
