输出尺寸是怎么定的

改 stride 或 padding，这一行会跟着变

out = ⌊(in + 2p − k) / s⌋ + 1 = ⌊(16 + 2×0 − 3) / 1⌋ + 1 = 14
输入边长 in
16
核边长 k
3
补零 p
0
步长 s
1

padding 选 valid 时 p = 0，每卷一次边长少 k−1 = 2；选 same 时 p = ⌊k/2⌋ = 1， 步长为 1 的情况下输出和输入一样大。步长 s 直接把输出边长缩小到约 1/s， 这是最省算力的降尺寸手段，代价是丢掉了中间那些位置的响应。
