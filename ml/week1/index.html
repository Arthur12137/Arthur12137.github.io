Week 1 Study Guide

第 1 周学习指南

四门课，九篇讲义。每篇对应一讲课件，按课件的页码顺序讲，术语、定义和小测都是中英对照。

每篇讲义的用法是一样的：

  1. 先看开头的学习目标。每条标了掌握程度：概念、辨析、计算、推导、编程。标「计算」「推导」的要能在纸上做出来。
  2. 对照课件 PDF 读正文。每一节的眉标写着对应的课件页码和英文节名。
  3. 在动手演示上做「自己试试」里的任务。每个演示都在浏览器里跑真实的算法，不是动画。
  4. 做最后的小测。题面英文在上、中文在下；答完会显示解析，说明为什么对、其它选项错在哪里。
  5. 把「中英术语表」里的英文说法记熟，考试和作业都是英文。

讲义里的数学都拆成了逐步推导：每一步写明做了什么、为什么可以这样做，下面标着这一步用到的规则。 某一步看不懂，点那个规则标签，会跳到数学工具箱里对应的一条，那里有解释和一个拆开算的小例子。

COMS30035 · Machine Learning

机器学习

本周讲义
  • L02机器学习的基本概念Machine Learning Concepts三种学习方式，外加五个贯穿整门课的概念：过拟合、模型选择、维度灾难、没有免费午餐、参数与非参数。
  • L04线性回归、线性判别与逻辑回归Linear Regression, Linear Discriminant and Logistic Regression最小二乘有闭式解；换成概率的眼光，它就是高斯噪声下的最大似然。分类问题把同一套思路接上一个 sigmoid。
这周最先要会的三件事
  1. 1在纸上用 θ̂ = (XᵀX)⁻¹Xᵀy 算出 lect04 p.7 那道 4 个点的最小二乘题（答案 y = 1.8 + 2.9x），再换一组数自己算。期中是闭卷纸笔，手算必须熟。
  2. 2从伯努利似然一路推到逻辑回归的梯度 Σ(yₙ − tₙ)xₙ，知道它是负对数似然的梯度（课件那一页漏了负号）。
  3. 3讲清过拟合、训练/验证/测试集、S 折交叉验证（S = N 即留一法），以及参数模型与非参数模型的区别。

COMSM0045 · Applied Deep Learning

应用深度学习

本周讲义
  • Lecture 01人工神经网络基础Basics of Artificial Neural Networks感知机用一个超平面把空间切成两半，能学会 OR，学不会 XOR；多加一层就能画出弯曲的分界面。
  • Lecture 02计算图与反向自动微分Towards Training Deep Forward Networks训练要所有权重的偏导。把网络写成计算图，一次正向、一次反向，就能拿到全部偏导。
这周最先要会的三件事
  1. 1手算感知机的逐步更新：给定 w、x、f*，算 s、f、Δw，能复现课件 OR 的训练表，并说出 XOR 为什么停不下来。
  2. 2从 J = 1/(2|X|) Σ(wᵀx − f*)² 推出 Delta 规则 Δw = −η x δ，并说出它和感知机规则的三处不同。
  3. 3在计算图上手算一遍正向和反向（f = 4、g = 2 时 a = 150，∂a/∂f = 60），记住「一个节点有多个使用者时 δ 要相加」。

COMS30030 · Image Processing and Computer Vision

图像处理与计算机视觉

本周讲义
  • Lecture 01图像的获取与表示Intro + Image Acquisition & Representation一张数字图像是连续光场经过镜头、采样、量化之后剩下的一张数字表。每一步都会丢信息。
  • Lecture 02图像滤波Filtering Images滤波就是拿一个小核在图上滑动做加权求和。平滑、去噪、锐化、找边缘，只是核里的数不同。
这周最先要会的三件事
  1. 1手算 3×3 的二维卷积和相关（MM02 p.7–8：同一块像素，卷积得 −68，相关得 68），知道核在 180° 旋转下对称时两者相同。
  2. 2说清采样和量化分别离散化了什么；采样率要高于最高频率的 2 倍，否则出现混叠。
  3. 3均值、高斯、中值、拉普拉斯、锐化各自做什么，哪些是线性的，高斯为什么可以拆成两个一维卷积。

COMS30094 · Intelligent Agents (and Multiagent Systems)

智能体与多智能体系统

本周讲义
  • Lecture 1什么是智能体Welcome to Intelligent Agents智能体是替人做决定的程序：它身处环境之中，自主选择动作，去完成交给它的目标。
  • Lecture 2智能体的性质、结构与环境Intelligent Agents: Properties, Architecture, and Environment同样的观测可能对应不同的世界，所以智能体要有内部状态；要往远处看，就得规划，而规划有成本。
  • Lab 1实验一：网格世界里的导航与乱扔垃圾Lab 1: Introduction to Agents同一个智能体里有两件事：导航算法决定往哪走，策略决定什么时候扔垃圾。策略写得差，它会把自己家门堵死。
这周最先要会的三件事
  1. 1背下智能体的定义（在环境中自主行动、完成被委托的目标）和四个特征：situated、autonomous、goal-directed、persistent。
  2. 2能区分反应式（aₜ = π(oₜ)）、基于模型（维护 bₜ）、基于目标、BDI 四种结构，能判断一个环境是否可达、确定、回合式、静态。
  3. 3做 Lab 1 时分清「导航算法」（BFS/DFS/A* 决定怎么走）和「策略」（决定什么时候丢垃圾），并能解释为什么基本策略会把自己家门堵死。

Connections

四门课之间的联系

这一周四门课讲的东西有不少重叠，同一个概念换了记号出现在两门课里。复习时对照着看，能省不少力气。

  • 感知机就是线性判别函数。深度学习里的 y = sign(wᵀx)（x₀ = −1，偏置被减去）和机器学习 lect04 的 y(x) = w₀ + wᵀx（偏置被加上）是同一个模型， 分界面都是一个超平面，只是 w₀ 的符号约定相反。
  • 三个梯度长得一样。Delta 规则 −η x (wᵀx − f*)、线性回归的 −2Xᵀ(y − Xθ)、逻辑回归的 Σ(yₙ − tₙ)xₙ，都是「误差 × 输入」。 原因是它们都对一个线性组合 wᵀx 求导，而链式法则最后一环 ∂(wᵀx)/∂w 总是 x。
  • 反向自动微分就是自动化的链式法则。机器学习 lect04 p.24 手推逻辑回归梯度用的就是链式法则；深度学习第 2 讲把它搬到计算图上，让程序去做。
  • 卷积是后面 CNN 的核心。图像处理 MM02 的二维卷积就是卷积神经网络每一层做的运算。区别是 CNN 的核是学出来的，而且 PyTorch 的 conv2d 实际做的是相关（不翻转核）。
  • 代价函数、性能度量、效用。机器学习里最小化损失，智能体课里最大化期望性能 argmax E[P | h, a]，是同一类「先定义好坏，再优化」的思路。
  • Minor 学生注意。机器学习和图像处理的 Minor 考核都放在 12 月的 Topics in Computer Science（COMS30081）考试里。
