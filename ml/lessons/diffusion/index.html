扩散模型

先学会把图像加噪，再反着走，就能从噪声里生成图像。

一张 512×512 的 RGB 图是 786,432 个数。让一个网络一次吐出这么多数， 还要求它们互相协调成一张说得通的图，用普通的均方误差训不出来： L2 回归的最优解是所有合理答案的平均值，落到图像上就是一张灰糊的平均脸。 GAN 换成让判别器来评分，绕开了这个平均，代价是要在两个网络之间维持平衡，训练容易崩。

扩散模型（diffusion model）换了个问法。它不要求一步生成，只要求把一张糊了一点的图修干净一点。这个子任务简单得多，而且训练数据是白送的： 拿任何一张真实图片，按已知强度加高斯噪声，就得到一对「输入、答案」， 答案就是刚才加进去的那份噪声。不需要人工标注，有多少图就有多少训练样本。 生成时把这个「修一点」的操作重复几十到上千次，从纯噪声一路修成图。

这一课的演示分两栏。二维那栏是真的在跑扩散：数据分布被限定成 二维高斯混合（Gaussian mixture），此时任意时刻的分布仍然是高斯混合，它的得分（score， 即对数密度关于 x 的梯度）有解析式， 所以正向加噪和反向采样都是逐步算出来的，没有神经网络也没有预录动画。 图像那栏只演示正向加噪与训练目标，因为真实图像的得分算不出来， 必须靠训练好的网络——本页没有这样的网络，也不会编造它的输出。

显示

这一栏的数字都是真的
数据分布被限定成二维高斯混合，于是 q_t 仍然是高斯混合，它的得分 ∇log q_t(x) 有解析式（各成分得分按后验责任度加权）。 反向采样用的就是这个解析得分换算出的 ε̂ = −√(1−ᾱ_t)·∇log q_t， 代入 DDPM 或 DDIM 的反向公式逐步采样。没有神经网络，也没有预录动画。 判据是右边那个「点云 log q_t 均值」：反向跑完之后它应该落回真实样本的参考值附近。
发生了什么

演示里发生了什么

正向过程是一条固定的、不含任何可学参数的加噪链。演示里每个点的位置是 按 xt​=αˉt​​x0​+1−αˉt​​ε 直接算出来的，同一个点在不同 t 用的是同一份 ε， 所以拖滑块时看到的是一条连续的轨迹，而不是每帧重新掷骰子。

拖的过程中盯着面板上的 αˉt​。 在默认的线性噪声调度（noise schedule）下，αˉ100​=0.132，αˉ200​=2.7×10−4。 也就是说到 t=200 时，原始数据在 xt​ 里的系数只剩2.7×10−4​≈0.016， 点云已经和标准正态没有可分辨的差别。这一点是必需的： 反向采样的起点是从 N(0,I) 里抽的， 如果 qT​ 还留着数据的形状，起点就是错的。

演示用的常数和原始 DDPM 不一样，这里说清楚：原始论文是 T=1000、β 从 10−4 线性升到 0.02， 终点 αˉ1000​≈4×10−5。 演示为了能实时跑完只有 200 步，照抄那组常数的话 αˉ200​ 还有 0.13，数据形状清晰可见。所以演示把 β 的终点抬到 0.08， 让 αˉT​ 同样落到 10−4 量级。 下面代码段里的数字按原始常数算，和演示面板对不上，属于正常。

背景热力图是 qt​ 的密度，逐像素用解析式算出来的。 高斯混合每个成分被加噪后仍是高斯：均值缩到 αˉt​​μk​，方差变成 αˉt​σk2​+(1−αˉt​)。 所以整个 qt​ 还是同样多成分的高斯混合，只是越来越胖、越来越挤在一起。

得分场画的是 ∇x​logqt​(x)， 也就是「从当前位置往哪挪一点，概率密度升得最快」。看两件事： 箭头指向最近的那团数据；而环形分布的正中心，10 个成分的拉力互相抵消， 得分严格等于零，那个格点上的箭头直接不画（13×13 的网格正好有一个点落在原点）；t=0 时数据附近的得分极陡，图下方的「场内最大 |∇log q_t|」在环形分布上是 51.6，在螺旋上是 131.2，而 t=200 时这个读数掉到 5 附近， 整个场退化成一个平缓的、指向原点的漏斗。这正是去噪网络要拟合的东西。

反向采样把解析得分换算成 噪声预测 ε^=−1−αˉt​​∇logqt​， 代进 DDPM（denoising diffusion probabilistic model）的反向公式， 从 t=200 一步步走到 t=0。 它不是在回放正向轨迹：起点是新抽的高斯噪声，每走一步都要在新位置重新算一次得分， 一轮 200 步就是 200 次得分计算。

怎么确认反向采样真的对

选「两团」这个分布。它的两个成分权重是 0.65 和 0.35，是写死在数据定义里的。 跑完反向采样，右上那团点应该占大约 35%。离线用 12 个不同的起点各跑 3000 个点， 得到的比例是 0.349，散布区间 0.337 到 0.365。

页面上默认只有 260 个点，二项抽样的标准差是 0.35×0.65/260​≈0.03， 实测 40 次单轮反向采样落在 0.26 到 0.41 之间。所以在页面上目测这个比例， 只能排除「明显不是 0.35」的错误（比如变成 0.5 或 0.2），不能用来验证第三位小数。 想读得准一点就把样本数 n 拉到 400。

另一个判据是面板上的「点云 log q_t 均值」。离线用五组各 4000 个点跑环形分布， 真实样本的平均 logq0​ 是 −2.258，DDPM 生成样本是 −2.199。 两者接近，说明采样落在了正确的分布上。生成样本略高一点是离散化的系统性偏差： 有限步的反向链会让样本轻微偏向密度更高的区域。页面上默认只有 260 个点， 这时单个点云的 log q 均值本身就有约 0.05 的抽样标准差， 所以读数不会和上面两个数精确对上，差值一般在 ±0.2 以内跳。 判据是「差值维持在零附近」，而不是某个具体数字；超过 0.35 面板会把这个读数标红。

两种调度的差别可以直接读数。同样 200 步， 线性调度在 t=100 时 αˉ 已经掉到 0.132， 余弦调度还有 0.494。线性调度把信号在中后段砍得太快， 相当于把大量步数花在「已经全是噪声」的区间里，那些步几乎学不到东西。 余弦调度就是为了修这个问题提出来的。

什么时候会失败：把采样器切到 DDIM（denoising diffusion implicit model），步数从 20 降到 5。环形分布会明显缩水一圈：点云平均半径从 1.47（20 步） 掉到 1.26（5 步），而真实样本是 1.52；log q 均值同时从 −2.14 掉到 −2.67。 步数太少时，每一步跨越的 αˉ 变化太大， 用当前点算出的 x^0​ 已经不足以代表整段区间。 这是所有少步采样器的共同代价，不是这个实现的 bug。

二维能精确，图像不能
这一课能跑出真反向，唯一的原因是数据分布被人为限定成高斯混合。 真实图像分布没有解析形式，∇logqt​(x) 算不出来， 只能训练一个网络去拟合它。所以演示的图像栏只做正向加噪： 那部分是纯算术，不需要任何模型。反向那一半没有模型就做不了， 页面上也不会用假数字冒充。

差别在误差怎么被放大。ε^ 有大小为 δ 的误差时，x^0​ 的误差是 δ⋅1−αˉt​​/αˉt​​， 也就是 δ/SNRt​​， 这里的信噪比（signal-to-noise ratio, SNR）定义为 SNRt​=αˉt​/(1−αˉt​)。 演示的图像栏可以直接量这件事： 把 δ 拉到 0.2，在默认的线性调度下 t=20 时放大系数只有 0.29 倍， 还原出的图基本没坏；t=180 时放大系数是 27.8 倍，同样的 δ 把图彻底毁掉。

所以两种参数化对应两种完全不同的隐式损失加权。用 ε 参数化、t 均匀采样，等价于对 x0​ 的加权 MSE，权重正好是信噪比—— 高噪声那一段被自动降权。这组权重在图像上训出来的效果比直接回归 x0​ 好， 但这是经验结论：ε 参数化本身不多带任何信息， 差别只在损失被怎么加权。 后来的 v-prediction 参数化就是在这条轴上继续调权重， 在极高和极低噪声两端都比 ε 稳。

为什么采样要走那么多步

两个原因，都能在演示里看到。第一，反向公式里那一步高斯近似只有在 βt​ 足够小时才成立——步子迈大了，q(xt−1​∣xt​) 根本不是高斯。第二，t 大的时候 1/SNRt​​ 是几十倍， 噪声预测的任何误差都会被放大到不可用，所以不能在高噪声处一步跳到 x0​。 每往回走一步 αˉ 变大一点，放大系数就小一点。

DDIM 的做法是换一族非马尔可夫但边缘分布完全相同的正向过程。 边缘分布一样，意味着训练好的 εθ​ 不用重训就能直接用； 而反向变成一个确定性映射，允许跳过中间的时间步。代价在演示里量得出来： 步数降到 5 时，生成分布明显缩水。工程上常用的 20 到 50 步是这个权衡的落点。

隐空间扩散（latent diffusion）：先压再扩散。上面所有公式对 x 的维度没有任何要求，所以可以不在像素上做。 Stable Diffusion 先用一个变分自编码器（variational autoencoder, VAE） 把 512×512×3 = 786,432 维压到 64×64×4 = 16,384 维， 正好是 48 分之一，再在这个隐空间里做扩散，最后解码回像素。 UNet 里的自注意力开销随 token 数平方增长，所以实际省下的算力比 48 倍还多。 代价是 VAE 的重建误差：小字、密集纹理和人脸细节会在压缩里丢掉， 这是隐空间扩散模型出图常见瑕疵的来源之一。

文本条件怎么进去。提示词先由一个文本编码器（CLIP 或 T5） 编成一串 token 向量，然后在 UNet 的每个分辨率块里插一层交叉注意力 （cross-attention）：query 来自图像特征，key 和 value 来自文本 token。 这就是第 12 课那套注意力，只是 query 和 key 来自两种不同的模态。 网络的输入因此多了一项条件 c，训练目标变成 ∥ε−εθ​(xt​,t,c)∥2。

无分类器引导（classifier-free guidance, CFG）一句话。训练时按大约 10% 的概率把条件换成空条件 ∅，于是同一个网络既会做有条件预测也会做无条件预测。 采样时把两者的差外推：

    把 δ 调回 0，再看一遍第四张图和 MSE 读数。
    MSE 会掉到 1e-33 到 1e-29（t 越大，舍入误差也被 1/√ᾱ_t 放得越大），也就是双精度浮点的舍入下限，读数变绿；t=0 时反解不做任何除法，MSE 精确显示 0。这验证了「完美预测 ε」和「完美还原 x₀」是同一件事——两种参数化互为确定的换算，不存在谁多知道一点信息。

这一课要带走的一句话

扩散模型把「一步生成」换成了「几十到上千次去噪」， 每一次去噪都是一个标签免费的普通回归。

分布的复杂形状是这条链一步步攒出来的，单步网络只需要预测一份噪声， 所以训练目标就是一个 MSE，没有对抗项也没有 KL 项要调。 代价记在采样时间上：出一张图要跑几十到上千次前向，比 GAN 的一次前向慢两三个数量级。 下一课换一种没有标准答案的学习方式——只有奖励信号的强化学习。
