模型评估

准确率会骗人，阈值一动，同一个模型的好坏结论就变了。

你写了一个筛查某种罕见病的分类器，在 2000 人的体检数据上测试，准确率（accuracy）98%。 这个数字可以写进汇报材料吗？不可以。这批人里本来就只有 2% 患病， 所以把模型换成一行「所有人都判为健康」，准确率同样是 98%，而且一个病人都查不出来。

问题不在于准确率算错了，而在于它只有一个数，把两种完全不同的错误混在了一起： 把健康人误判为病人（假阳性 false positive，也叫误报）， 和把病人漏判为健康（假阴性 false negative，也叫漏报）。 这两种错误的代价差得很远，用一个数概括就必然丢掉信息。

还有一件事容易被忽略：分类模型输出的其实不是类别，而是一个分数。model.predict(x) 之所以直接给出 0 或 1，是因为它内部悄悄用了一个阈值 （threshold，通常是 0.5）。这个阈值不是模型训练出来的，是你选的。改它，模型的权重一个都没变， 但准确率、精确率（precision）、召回率（recall）会同时改变，而且方向不一致。

发生了什么

这里面到底发生了什么

演示里只有三样东西：一堆分数、一条阈值线、四个格子。剩下的所有指标都是从这四个格子里算出来的。

  • 模型给的是分数，不是类别。两堆分数有重叠区，重叠区里既有病人也有健康人。只要重叠区不为空， 无论阈值放在哪，都必然同时存在误报和漏报。这不是模型没训练好， 是这份数据本身能达到的上限。
  • 阈值把一个模型变成一整族分类器。拖动竖线时，分数一个都没变，混淆矩阵却一直在变。所以「这个模型好不好」 这个问题问得不完整——必须先说清楚阈值定在哪。
  • 阈值往右走，召回率一定下降，精确率只是倾向于上升。把阈值提高等于提高报警门槛：报警次数变少，更多真病人被挡在门外。 召回率的分母是固定的阳性总数、分子只减不增，所以它随阈值单调不增，这是恒成立的。 精确率的分母是报警次数，分子分母一起缩，只是趋势向上，中途完全可以回落： 切到「欺诈检测」预设（不重新采样）把阈值从 0.848 移到 0.898，精确率 0.091 → 0.250， 再移到 0.948 就掉回 0.000，因为最后几次报警恰好全错。
准确率在类别不平衡时基本没有信息量

在「罕见病」预设下把阈值推到 1.0，准确率是 98.0%。把阈值拉回 0.5，准确率掉到 0.83， 但召回率从 0 涨到 0.82——从查不出任何病人，变成 40 个病人查出了 33 个。

也就是说，在这份数据上准确率变低反而意味着模型开始干活了。 任何一个分类结果，都应该先和「全猜多数类」这个常数基线比一比： 如果准确率没有明显超过多数类的比例，这个数字就不能当成成绩。

那怎么摆脱阈值的干扰？把阈值从 1 一路滑到 0，每个位置记下一对 (FPR,TPR)，连起来就是 ROC 曲线。 曲线上的每一个点是一个阈值，整条曲线描述的是这个模型排序能力的全貌： 它有没有把病人的分数普遍排在健康人前面。曲线下面积 AUC 就是这个排序能力的一个总结数字， 和你最后选哪个阈值无关。

把「可分离度」滑块拖到 0，两堆分数完全重合，ROC 会塌到对角线上，AUC ≈ 0.5。 对角线的含义是抛硬币：想多抓 10% 的病人，就得多冤枉 10% 的健康人。

AUC 高，不代表能直接用

ROC 横轴 FPR 的分母是全部阴性样本数。在「罕见病」预设、阈值 0.5 处，模型误报了 335 次， 但阴性总共有 1960 个，所以 FPR 只有 0.17，整条 ROC 明显鼓向左上角，AUC 在 0.9 以上。 同一个阈值下精确率却只有 0.09：报警十来次才碰上一个真病人。

所以在正类极少的场景里，ROC-AUC 会系统性地显得乐观。这类问题要额外看 PR 曲线 （横轴召回率、纵轴精确率）和它的面积 average precision， 因为精确率的分母是「报警次数」，不会被庞大的负样本稀释。

四个格子加起来等于样本总数。下面所有指标都只是这四个数的不同组合，区别只在于拿谁做分母。

分母为 0 时这两个量是未定义，不是 0 也不是 1。 演示里把阈值推到 1.0 后精确率显示「未定义」，就是因为 TP+FP=0： 模型一次警都没报，谈不上报得准不准。sklearn 在这种情况下会发一条 UndefinedMetricWarning，然后按 zero_division 参数填一个值—— 那是个约定，不是数学结论。

要把两个指标合成一个数，用的是调和平均（harmonic mean）：

为什么不用算术平均？因为算术平均可以被单边刷分。假设阈值调得极高， 模型只对最有把握的那一个样本报警，而且报对了：精确率 = 1.00， 但 40 个阳性只找到 1 个，召回率 = 0.025。 算术平均是 (1.00+0.025)/2=0.51，看着像及格； 调和平均是 2×1.00×0.025/1.025=0.049，直接判不及格。 调和平均对小的那一个数敏感，因为取倒数会把小数放大， 所以只有两个指标都不低时 F1​ 才高。

F1​ 的失效条件也在这个式子里：它把精确率和召回率的权重写死成一比一， 等于假设一次误报和一次漏报同样严重。癌症初筛不满足这个假设，用 F1​挑阈值就会挑得偏高。这种情况要换成本节最后那个 Fβ​。

还有两个指标是站在阴性样本一侧看问题的——特异度（specificity）和假阳性率 （false positive rate，FPR）：

ROC 曲线（receiver operating characteristic）就是把阈值 t 从 +∞ 滑到 −∞， 把每个 t 对应的点连起来：

t 极大时没有样本被判为阳性，落在 (0,0)；t 极小时所有样本都判为阳性，落在 (1,1)。 曲线一定从左下角走到右上角，问题只是它中间鼓得有多高。 AUC 是这条曲线下的面积，它有一个干净的概率解释：

读法是：随机抽一个真实阳性样本 X+ 和一个真实阴性样本 X−，模型给阳性样本的分数更高的概率就是 AUC。 AUC = 0.5 表示排序完全随机；AUC = 1.0 表示存在某个阈值能把两类完全切开。 注意它衡量的是排序，不是校准：一个把所有分数都乘以 0.001 的模型，AUC 一模一样， 但 0.5 这个阈值会彻底失效。

该看精确率还是召回率，取决于两种错误的代价谁更大

这不是一个数学问题，公式本身给不出答案。要先回答的是：在你的场景里， 一次误报和一次漏报，哪个后果更严重？

  • 看精确率：垃圾邮件过滤。把一封正常邮件扔进垃圾箱（FP）， 用户可能永远看不到它；而漏掉一封垃圾邮件（FN）只是烦一下。所以阈值应该调高。
  • 看召回率：癌症初筛。漏掉一个病人（FN）代价是生命； 误报一个（FP）的后果是多做一次确诊检查。所以阈值应该调低， 让后面的确诊环节去清理误报。
  • 两者都要：没有明确代价差异时用 F1​； 如果知道漏报比误报严重 β 倍，可以用 Fβ​=(1+β2)β2Precision+RecallPrecision⋅Recall​，β=2 时召回率的权重是精确率的四倍。

选阈值必须在验证集上做
用测试集去挑 F1 最高的阈值，等于把测试集的信息漏进了模型，报出来的分数会偏高。 正确做法是在验证集上选定阈值，再拿到测试集上跑一次，只报这一次的结果。 这属于第 05 课要展开的话题。
自己试试

自己试试

  1. 1
    保持「罕见病」预设，点右边红色的「全预测为阴性」，读准确率和召回率。
    准确率 0.980，召回率 0.000。混淆矩阵「预测阳性」那一整列是 0，精确率显示「未定义」。这个 98% 完全由 1960 个真阴性贡献，和模型无关。
  2. 2
    接着把阈值从 1.0 慢慢拖到 0.5，盯着准确率那个数看。
    准确率从 0.980 一路掉到 0.83，召回率却从 0 升到 0.82。同一次拖动里，一个指标变差、另一个变好——这就是为什么不能只报一个数。
  3. 3
    打开「纵轴按真实数量」开关。
    上半部的阳性直方图几乎塌成一条线：40 例阳性对 1960 例阴性，画在同一把尺子上就是这个比例。关掉开关后两类各自归一化，形状才看得清，但要记住真实的数量差。
  4. 4
    切到「欺诈检测」预设，连点八次「重新采样」，每次记下 AUC，以及阈值滑块下面那行「F1 最高」的数值。
    AUC 在 0.63 到 0.82 之间跳；「F1 最高」晃得更凶，0.03 到 0.24 都出现过，相差近 8 倍。原因是这个预设下阳性只有 10 个，召回率的分母就是 10，多抓到一个就跳 0.1。分布参数一个都没改，只换了随机种子——阳性样本这么少时，两个模型差 0.05 的 AUC 说明不了任何问题。
  5. 5
    把「可分离度」滑块拖到 0，然后随便怎么拖阈值。
    ROC 塌到对角线上，AUC ≈ 0.5。此时无论阈值放在哪，精确率都约等于正类比例——报警不携带任何信息。AUC 低于 0.5 也可能出现，那只说明分数的方向反了，把分数取负号就回到 0.5 以上。
  6. 6
    点阈值滑块下面的「F1 最高」跳到最优阈值（罕见病预设下是 0.637），再往左右各拖 0.05，记下三个指标各变多少。
    0.637 处 F1 = 0.316、精确率 0.214、召回率 0.600。往左到 0.587，F1 掉到 0.245，召回率涨到 0.675、精确率跌到 0.150；往右到 0.687，F1 掉到 0.294，召回率跌到 0.400、精确率涨到 0.232。F1 最大的位置是这两个指标的折中点，不是任何单个指标的最优点。

这一课要带走的一句话

报告一个分类模型的效果，至少要说清楚三件事：阈值定在哪、 两种错误各有多少、以及和常数基线比高出多少。

下一课换一个角度问同样的问题：这些指标是在训练数据上算的，还是在没见过的数据上算的？ 两者差多少，就是第 05 课要量的东西。
