第 16 课·现代 AI

现代 AI 全景

今天的大模型、扩散模型和机器人策略，共用同一套底层零件。

前面十三课把零件拆完了：模型是一个带参数的函数，损失是一个把「好坏」压成一个数的公式， 梯度下降负责把参数往损失小的方向挪，反向传播负责把梯度算出来， 卷积和注意力是两种特定形状的层。到这里为止，你手上的工具已经够用了。

现在打开任何一篇技术报道，会看到另一套词：基础模型（foundation model）、 大语言模型（large language model，LLM）、扩散模型（diffusion model）、 VLA（vision-language-action，视觉—语言—动作）、世界模型（world model）、 涌现（emergence）、scaling law（规模律）。这些词听上去像是新东西， 但把它们拆开之后，里面装的还是上面那几个零件， 换掉的通常只有两样：输入输出是什么，和损失函数怎么写。

这一课不深挖任何一个方向——每个方向后面都有专门的一课或者一整个领域。 这一课只做一件事：把这些名词摆在同一张图上，标清楚谁用了谁的零件， 这样你读到一篇论文时能判断它属于哪一支、需要先补哪一课。 顺便把几个被用得最含糊的词定义清楚，以及指出哪些流行说法经不起细看。

发生了什么

这张图该怎么读

先看主干。从根走到基础模型要经过四个方框、三条边，每条边换掉的是一件具体的事：

  • 机器学习 → 深度学习：换掉「特征由人设计」。 经典方法要求你先把房子变成面积、楼层、房龄这几列数字； 深度学习直接吃原始像素，中间的表示自己学。
  • 深度学习 → Transformer：换掉「序列按顺序读」。 循环网络第 t 步必须等第 t−1 步算完， 注意力让所有位置同时算，训练才吃得满 GPU。
  • Transformer → 基础模型：这一步没有换模型结构， 换的是训练流程——从「每个任务单独训一个模型」变成「先预训练一个大的，再适配到各个任务」。

再看分支。基础模型下面挂的八个方向里，前六个（大语言模型、视觉 Transformer、 视觉语言模型、扩散模型、世界模型、VLA）的网络结构基本都是 Transformer 或卷积网络， 区别在于喂进去什么、吐出来什么、以及损失怎么算。这也是这张图想说的主要一件事。 剩下两个不一样：强化学习和具身智能描述的是问题设定， 不是某一种网络结构——它们规定了数据怎么来、成功怎么判定， 至于策略网络用 MLP 还是 Transformer，是另一件事。

这张图有一处画不准：每个方框只画了一个父节点，实际依赖不止一条。 VLA 同时用到视觉语言模型和模仿学习（imitation learning）， 扩散模型的去噪网络多数是卷积网络， 具身智能同时用到 VLA、强化学习和世界模型。 画成一棵树是为了看得清主干，代价是丢掉了这些横向的边。 点开任意方框，右侧「依赖前面哪些技术」那一栏写的才是完整的依赖。

每个方向 = 一组已知零件的组合
  • 大语言模型 = Transformer 解码器 + 「预测下一个词」这个损失 + 规模
  • 扩散模型 = U-Net 或 Transformer + 「预测加进去的噪声」这个损失 + 迭代采样
  • CLIP / 视觉语言模型 = 两个编码器 + 「配对的拉近、不配对的推远」这个损失
  • VLA = 视觉语言模型 + 把动作切成 token + 模仿学习（拿人类演示当监督信号）
  • RLHF（reinforcement learning from human feedback，用人类反馈做强化学习） = 第 18 课那个「只有奖励、没有标准答案」的框架 + 一个用人类比较数据训出来的奖励模型。 第 18 课讲的是 Q-learning，RLHF 实际用的是 PPO 这类策略梯度方法，两者都属于强化学习， 但更新公式不一样。
  • 世界模型 = 序列模型 + 「预测下一个状态」这个损失

最后看虚线边。图里有四条边是往回指的：深度学习 → CNN、深度学习 → 循环网络、 基础模型 → 强化学习、基础模型 → 世界模型。它们的子节点比父节点出现得更早—— Q-learning 是 1989 年的方法，比 AlexNet 早 23 年。这张图的箭头表示「今天用了谁的零件」，不表示「谁先出现」。打开时间轴模式，这四条边会明显地往左指。

「基础模型」到底指什么

这个词是斯坦福在 2021 年的一份报告里提出来的，指在大规模广泛数据上训练、可以适配到大量不同下游任务的模型。 注意定义里没有一个字提到网络结构。它描述的是一套流程，这套流程分成两段：

  • 预训练（pre-training）：用海量无标注数据 + 一个自监督目标， 训出一套通用表示。这一段吃掉了总算力的绝大部分，一次训练几周到几个月。 做这件事的通常是少数几家有卡的机构。
  • 适配（adaptation）：可以是微调（fine-tuning，改参数， 而且往往只改很小一部分，见后面的 LoRA）， 也可以是提示词（prompting，一个参数都不改，把任务描述写进输入）。 这一段的数据量和算力通常比预训练小两三个数量级，一张消费级显卡就能做。

这个分工能成立的前提是：预训练学到的表示，对下游任务确实有用。 在互联网数据覆盖得好的领域（自然语言、常见物体的图像），这个前提基本成立。 在覆盖不到的领域——机器人的接触力信号、工厂设备的振动时序、特定仪器的原始读数—— 预训练模型没见过这类数据，优势不会自动转移，你还是得自己收集数据从头训。 机器人领域现在最大的困难就是这个：数据要真机采，量级比互联网文本小六到七个数量级。

自监督为什么能绕开标注瓶颈

监督学习的成本卡在标注上。ImageNet 有 128 万张训练图，每一张都要人看一眼写下类别。 想把数据量再放大一千倍，标注成本也要放大一千倍，这条路走不通。

自监督（self-supervised）的做法是：把答案从数据本身里挖出来， 不额外雇人。三个典型例子：

  • 文本：把第 t 个词遮住，让模型根据前面的词猜它。答案就是原文。
  • 图像：遮住若干个图块，让模型把像素补回来。答案就是原图。
  • 图文：网页上的图片和它旁边的说明文字天然配对。答案就是「这两个是一对」。

这样一来，训练数据量的上限从「能雇多少标注员」变成「能爬到多少数据」， 一下子放大了好几个数量级。代价是：自监督的目标函数和你真正关心的任务只是相关，不是同一件事。 把下一个词预测练到极致，并不直接等于会按人的意图回答问题。 从预训练模型到能用的对话模型中间还隔着监督微调和 RLHF 这两步， 这两步用的还是人工标注的数据，只是量小得多。

scaling law：一句话结论和三条边界

一句话结论：在训练配方固定的前提下，测试损失随参数量、数据量、 算力按幂律（power law）下降，写出来是 L(C)≈L∞​+aC−α，其中 C 是算力，L∞​ 是不随规模下降的那一部分（数据本身的随机性）。 关键在于 α 很小：Kaplan 等人 2020 年对算力拟合出的αC​≈0.05。幂律画在双对数坐标上是一条直线， 画在普通坐标上是一条很快压平、并且停在 L∞​ 上的曲线。 所以这个结论的实际含义是：想让损失再降一点点，算力要成倍地加， 而且再怎么加也降不到 0。

这里有一处要说清楚：Kaplan 等人原文拟合的是纯幂律 L(C)≈aC−α，没有 L∞​ 这一项，所以那条曲线外推下去会一直降到 0； 带 L∞​ 的三项写法是 Hoffmann 等人 2022 年 （Chinchilla）用的形式。上面这个式子取的是后者，因为它更接近实际观察到的行为。 两种写法在拟合区间内几乎重合，外推出去差别很大，这本身就是下面第一条边界的例子。

三条边界，每一条都会在实际项目里咬人：

  • 只在拟合区间内可信。曲线是用一批实际跑过的模型拟合出来的。往外推一两个数量级还算合理， 推四五个数量级就是外插，没有任何保证。
  • 换个实验设计，结论就变。Kaplan 等人 2020 年的结论是算力应该优先加在参数量上； Hoffmann 等人 2022 年（Chinchilla）用同样的方法重做， 结论是参数量和数据量应该同比例增长，大约每个参数配 20 个 token， 当时的大模型普遍训练不足。两份工作方法相同、结论相反。 这说明幂律是对一批实验的拟合，不是物理定律。
  • 损失下降不等于任务变好。scaling law 里的损失是 token 级别的对数似然，你关心的是任务成功率、 事实正确率、代码能不能跑。两者之间没有固定换算关系， 甚至可能在某段区间内不同步。
被夸大的三个说法
  • 「涌现」：流行说法是模型规模过了某个点会突然长出新能力。 Schaeffer 等人 2023 年指出，这个台阶在很大程度上是指标选出来的：如果用 exact match 这种答对全给分、 差一个字符就是 0 的指标，小模型全部记 0，曲线看起来就是突变； 换成 token 级别的连续指标（对数似然、编辑距离），同一批模型的曲线是平滑上升的。 台阶不一定是模型的性质，可能是尺子的性质。这不意味着大模型没有变强， 只意味着「突然」这个词用得太随意。
  • 「理解」「推理」：模型在某个基准上得分高， 不等于它在做人类意义上的推理。把同一道题换个说法重问、 或者只把里面的数字改掉，分数经常明显下降。基准分数衡量的是在这个基准上的表现， 外推到「它会推理」需要额外证据。
  • 「通用」：通用是相对于训练数据分布说的。 一个在互联网文本上训练的模型，在互联网覆盖的话题上通用； 在没被覆盖的领域（专业设备日志、机器人力控信号）它既不通用也不可靠， 而且它不会告诉你自己不知道。

两个常见误解

第一，LoRA 不是「更快的微调」，它是「更省显存的微调」。 前向计算多了一个旁路，单步反而略慢；省下来的是优化器状态和梯度的显存。

第二，微调改变不了模型没学到的知识。 如果预训练数据里根本没有你这个领域的内容， 用几千条样本做 LoRA 只能改变它的说话风格和输出格式，改不出它不知道的事实。
