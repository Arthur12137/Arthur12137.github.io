第 13 课·深度学习

Transformer

注意力让每个词按需要去看别的词。

给模型读这句话：「机器人把杯子拿起来，然后把它放进水槽」。 要判断「它」指的是杯子还是机器人，模型必须能从「它」这个位置回头看到前面第三个词。 循环神经网络（RNN）的做法是把读过的内容压进一个固定长度的隐状态，一步一步往后传； 隔得越远，早先的信息在反复覆写中留下的越少，而且每一步都要等上一步算完， 整条序列没法并行。

自注意力（self-attention）换了个做法：每个位置直接和序列里所有位置各算一次相关度， 再按相关度把它们的信息加权取回来。「它」和「杯子」之间永远是一步， 中间隔 3 个词还是 3000 个词都一样。代价是每一层要算 n2 个相关度，n 是序列长度。

本课不讲 RNN 的细节。关于它，现在只需要知道它为什么被换掉： 顺序依赖挡住了并行，长距离信息会衰减。2017 年的 Transformer 把循环结构整个拿掉， 只留下注意力和前馈网络（feed-forward network，FFN），今天几乎所有大模型都是这个结构的直接后代。

发生了什么

注意力到底在算什么

抛开所有矩阵符号，自注意力只做三件事，对每一个位置各做一遍：

  1. 算相关度：拿这个位置的 q 和所有位置的 k 做点积，得到 n 个分数。
  2. 归一化：这 n 个分数除以 d​ 再过 softmax，变成加起来等于 1 的权重。
  3. 加权求和：按这组权重，把所有位置的 v 加起来， 作为这个位置的新表示。

演示里那两张并排的矩阵，左边是第 1 步的结果（有正有负，量级随便）， 右边是第 2 步之后的结果（每行都是一个概率分布）。第 3 步的结果就是右边那个 「输出 = Σ wj vj」的向量。

Q、K、V 的检索类比

同一个输入向量乘三个不同的矩阵，得到三个含义完全不同的东西：

  • query（查询）：我要找什么。相当于你在搜索框里打的字。
  • key（键）：我是什么。相当于每篇文档的标题，用来被匹配。
  • value（值）：我能提供什么。相当于文档正文，真正被取回去的内容。

和数据库检索的区别在于：数据库是硬匹配，命中一条就返回一条； 注意力是软匹配，所有文档都返回一点，按匹配程度加权。 正因为是加权平均，整个过程可导，可以用梯度下降训练。

为什么要除以 d​。设 q 和 k 的每个分量都是独立的、均值 0 方差 1 的随机数， 那么点积 q⋅k=∑i=1d​qi​ki​ 的期望是 0， 方差正好是 d，标准差是 d​。 维度越高，分数拉得越开。softmax 对输入的绝对尺度极其敏感： 分数之间差 10，权重比就差 e10 ≈ 22026 倍， 结果几乎就是 one-hot——每个位置只看得见一个 token，而且这时 softmax 的梯度接近 0，训不动。

演示里那张「随机向量实测」的表不是抄来的数字，是页面加载时真采样算出来的： 第二列几乎正好等于 d​，第三列显示不缩放时 d=256 的最大权重已经到 0.93 以上，也就是 8 个 key 里一个吃掉 93%。 除以 d​ 之后（第四列）， 四个维度的最大权重都稳定在 0.35 附近，尖锐程度和维度基本无关。

多头是干什么的。 一次 softmax 只能给出一种权重分配。 但「picks」这个位置同时需要知道两件事：它作用在哪个物体上，以及谁在执行这个动作。 单头必须把这两种关系挤进同一个分布里，只能给出一个折中。 多头（multi-head）把 dmodel​ 切成 h 段，每段独立算一次注意力， 最后拼回来。在演示里把句子保持在英文、头数切到 4：头 0 里 picks 给 cup 的权重是 0.838， 头 2 里 picks 转去看 robot（0.286，是那一行最大的）， 头 3 只剩位置通道，除了位置编码为 0 的句首那一行是均匀的，其余每一行从左到右单调增大。 这几张图不一样，才是多头存在的理由。演示的解说会按当前句子和头数实时算出每个头最尖的那一格， 切换设置时数字会跟着变。

要注意的是，「不同头关注不同关系」是训练之后才出现的现象。 把权重切到「随机初始化」，各个头的矩阵都是接近均匀的糊，彼此也没有分工。 结构本身不保证分工，只是提供了分工的空间。

位置编码为什么必须有。 把演示里的「加入位置编码」关掉， 再看注意力矩阵：The 和 the 对应的两行两列完全相同。 原因是自注意力本身是置换等变（permutation equivariant）的—— 交换输入里两个 token 的顺序，输出也只是跟着交换，内容一个字都不变。 它算的是集合，不是序列。词序这个信息必须由外部显式注入， 最常见的做法就是把一组和位置有关的数加进（或乘进）每个 token 的向量。

一个常见的误读：注意力权重不等于解释
权重大只说明这两个位置在这一层的这个头里点积大，不说明模型「因为」它才做出某个判断。 同一个预测常常可以在权重分布很不一样的情况下复现。 把注意力图当成模型的因果解释，是这几年被反复指出的错误用法。
自注意力什么时候不是更好的选择

两个明确的失效条件。第一，数据少的时候。卷积自带局部性和平移不变性这两条先验， 自注意力把它们全扔了，所有位置对一视同仁，缺的东西只能从数据里学回来； 在几万张图这个量级上，ViT 打不过同规模的 CNN，要靠大规模预训练或强数据增强才追平。

第二，序列很长的时候。每一层要算 n2 个相关度， 长度翻倍算量翻四倍，下面那张表给了具体数字。所以长上下文模型不是简单地把 n 调大，而是要换掉这一步的算法。

发生了什么

一个 block 里除了注意力还有什么

注意力只占一个 block 的一半。剩下的三样东西——残差、LayerNorm、前馈网络—— 都不是装饰，去掉任何一个，深层网络就训不起来。

残差连接（residual connection）是逐元素相加，没有任何参数。它有两个作用。 一是子层只需要学「要改动多少」，而不是从零重建整个向量； 子层输出全 0 时这一层就是恒等映射，不会把已有信息弄坏。 二是反向传播时 ∂(x+f(x))/∂x=1+∂f/∂x， 那个常数 1 提供了一条不衰减的梯度通路，直达底层。 这是 2015 年 ResNet 给出的结论，Transformer 直接沿用。

层归一化（layer normalization，LayerNorm）对每一个 token 自己的那几百个数求均值和标准差，减掉均值再除以标准差，最后乘一个可学的 γ 加一个可学的 β。它不跨 token、不跨 batch， 所以推理时一条一条算和成批算结果完全一样——这正是它比 BatchNorm 更适合变长序列的原因。 它要解决的问题是：残差不断把东西加上去，向量的尺度会一层层放大， 后面的 softmax 和 ReLU 会被推到饱和区。

演示里的 LayerNorm 默认设成了恒等映射，这一点在那个面板里写了原因： 本课的玩具嵌入只有 4 维，而且把语义编码在长度上， 归一化会把接近零的向量放大到和别的一样长，手工设计的语义就被抹掉了。 真实模型有 768 到 8192 维，语义分布在成百上千个维度的方向上，不会有这个问题。 把开关切到「标准」可以亲眼看到这个失效点。

前馈网络是一个两层的多层感知机（MLP），逐位置独立作用：第 3 个 token 和第 5 个 token 走同一组权重，互不影响。中间层通常是 dmodel​ 的 4 倍 （768 → 3072 → 768），Transformer 大约三分之二的参数在这里。 一个有用的读法是把它看成键值记忆：第一层的每一行是一个「检测器」， ReLU 决定它是否被触发，第二层决定被触发之后往表示里写什么。 演示里那 8 个带名字的隐藏单元就是按这个思路手工设计的。

整个 block 的输入输出形状完全一样，都是 n×dmodel​。 这就是它能被原样复制 12 遍、32 遍、96 遍的原因。

三个最常见的实现错误

一，softmax 忘了减最大值。 分数稍大就 exp 溢出成 inf，再相除得到 nan，而且不报错，只是 loss 突然变 nan。

二，缩放用了 d_model 而不是 d_k。 多头时每个头的维度是 d_model / h，除错了会让 softmax 系统性偏软或偏硬。

三，掩码用 0 而不是 -inf。 把分数置 0 之后 exp(0) = 1，被掩掉的位置反而拿到了不小的权重。 必须在 softmax 之前置成 -inf。

延伸

这一课要带走的一句话

自注意力就是：每个位置拿自己的 query 和所有位置的 key 算相似度， softmax 成一组加起来等于 1 的权重，再把所有 value 按这组权重加起来。

其余零件各自处理一个具体故障。除以 √d 是防止 softmax 饱和成 one-hot 之后梯度消失； 多头是因为一次 softmax 只能给出一种权重分配；位置编码是因为这个操作本身置换等变， 分不出词序；残差和 LayerNorm 是为了让层数能堆到几十层还训得动。 这一课里出现的每一个数，都可以在上面两个演示里点开重算一遍。
