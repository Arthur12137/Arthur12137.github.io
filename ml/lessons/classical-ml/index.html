第 06 课·经典机器学习

经典算法对比

同一份数据换不同算法，分界面的形状完全不一样。

一家医院想从体检记录里挑出需要复查的人。数据是几千行的表格，特征是十几个化验值， 标签是「后来确诊了没有」。这种任务上排第一的方法通常不是神经网络，而是梯度提升树。 表格数据的样本量太小、特征之间又没有图像那种空间结构，深度模型拿不到优势。

这一课把五个方法放在同一份二维数据上，只盯着一件事看：它们画出来的分界面长什么样。 分界面的形状就是这个算法对世界的假设。KNN 假设「附近的点标签相同」； 决策树假设「几刀水平和竖直的切割就能分开」；SVM 假设「存在一条离两类都尽量远的界」。 假设和数据对不上的时候，训练再久也补不回来——演示里同心圆配线性核那一格， 准确率永远停在六成出头，不是没训够。

SVM（RBF 核）由每个支持向量周围的高斯「鼓包」叠加出的光滑曲面γ 小时不敏感；γ 调大就退化成给每个训练点画一个圈低：系数挂在支持向量上，读不出特征含义样本上万时（核矩阵是 n×n，训练和预测都吃不消）
发生了什么

五个算法各自在做什么

KNN（k-nearest neighbors，k 近邻）： 读数里那个「拟合耗时」在 KNN 上是 0.0 ms，因为它的训练阶段真的什么都不做， 只是把训练集原样存下来。代价全在预测：每问一个点，都要跟所有训练样本算一遍距离， 取最近的 k 个投票。把鼠标放到图上，画出来的那几条连线就是投票者， 虚线圈的半径是第 k 近的距离。k 越大，圈越大， 边界越平滑；k 大到把整片结构都圈进去，就只剩多数类了。

决策树（decision tree）：每一步只能沿着一个坐标轴切一刀， 所以边界只由水平和竖直的线段组成。 打开树结构那张图，点任何一个节点，左边会高亮它管辖的矩形。 一棵深度 d 的树把平面切成最多 2d 个矩形， 每个矩形里投一个固定的票，节点与矩形是一一对应的。 斜的分界面它只能用阶梯去逼近，所以在螺旋数据上深度 4 只有 71.4% 的训练准确率。

随机森林（random forest）：造很多棵互不相同的树，再把它们的概率平均。 「互不相同」有两个来源，缺一不可：每棵树只用 bootstrap（有放回抽样）抽到的那部分样本； 每次分裂时只能在随机抽到的特征子集里找切分点（这里只有两个特征，所以每次随机选一个）。 那一排缩略图就是前六棵树各自的边界，单看每一张都又糙又偏，平均之后才平滑。 在双月数据上，一棵树的袋外（out-of-bag，简称 OOB）准确率是 83.8%，24 棵树是 85.5%。

梯度提升（gradient boosting）：树不是并行造的，而是一棵接一棵串起来。 第 m 棵树拟合的不是标签，是前 m−1 棵树还差多少， 也就是残差（residual）yi​−σ(Fm−1​(xi​))。 点「逐轮播放」能看到边界一轮一轮长出细节。下面那条损失曲线一直在降， 但降的是训练集上的损失——轮数继续加，训练损失还会降，泛化却已经在变差了。

SVM（support vector machine，支持向量机）： 在所有能把两类分开的直线里，挑离两边都最远的那条。两条虚线是 w⋅x+b=±1，中间那条带子的宽度是 2/∥w∥。被加粗描边的点是支持向量： 只有它们参与决定这条线的位置，把其余的点删掉，解一模一样。 换成 RBF 核之后，直线变成由每个支持向量周围的高斯鼓包叠出来的光滑曲面。 这一栏的热力图和别的算法不同：SVM 的决策函数 f(x) 不是概率， 图上的颜色是 σ(f(x))，压进 (0,1) 只为了配色， 不要当成「有多大把握」来读。

边界形状 = 归纳偏置

五个算法看的是同一份数据，却画出五种完全不同的边界。差别不来自数据， 来自每个算法「愿意画出什么形状」的先验限制，这个限制叫归纳偏置（inductive bias）。 选模型的第一件事不是比准确率，是判断你的数据像不像这个算法愿意画的形状。 演示里的六个数据集就是六种形状：线性可分适合 SVM，同心圆必须上核， 螺旋对轴平行的树很不友好，异或对单刀直线是死局。

训练准确率在这一课里几乎没有用

把 k 拨到 1，训练准确率立刻变成 100%——因为离每个训练点最近的点就是它自己。 这个数字没有任何信息量。演示里给 KNN 单独加了一个 「留一法（leave-one-out）准确率」，预测每个点的时候把这个点自己从训练集里拿走， 它才是可信的：螺旋数据上 k = 1 的训练准确率是 100%，留一法只有 96.8%。 打开「按 1/距离 加权投票」之后情况更糟：查询点落在训练点上时距离是 0， 那一票的权重压过其余所有邻居，于是 k 取多少训练准确率都是 100%。 随机森林那一栏的「袋外准确率」是同一个思路：每个样本只让没抽到它的那些树来投票。 第 05 课讲的训练误差与泛化误差的差距，在这里是可以一个滑块就看出来的。

一、决策树怎么挑切分点。要挑一刀，得先有办法衡量「一堆样本有多混」。Gini 不纯度（Gini impurity）的定义是： 从集合里独立地随机抽两个样本，它们类别不同的概率。

全是一类时 G=0；两类各半时 G=0.5，这是二分类的最大值。 右边那个 H(S) 是信息熵，作用一样，只是尺度不同（两类各半时等于 1）。 一次切分把 S 分成 SL​ 和 SR​，收益是加权不纯度的下降：

算法在两个特征上分别把样本排序，对每一对相邻的不同取值取中点作为候选阈值， 扫一遍算出所有 Δ，选最大的那个。这是贪心的： 只看这一刀能降多少，不管后面还能不能补救。所以决策树不保证找到全局最优的树， 找全局最优树是 NP 难的。演示里树结构那张图，每个节点上写的G=0.42 就是这个 G(S)。

第一项 ρσ2 不随 M 变， 这就是随机森林非做特征随机化不可的原因：只做 bootstrap 的话， 每棵树的根节点大概率还是挑同一个特征、同一个阈值，ρ 接近 1， 平均下去省不了多少。强行让每次分裂只能看部分特征，是在故意把每棵树弄差一点， 换来它们之间的不相关。演示里那六张缩略图彼此差得越远，第一项就越小。

右边正好是残差：真实标签减去当前预测的概率。所以「用一棵回归树去拟合残差」 这句话的精确含义是在函数空间里沿着负梯度走一步， 这也是「梯度提升」这个名字的由来。第 02 课的梯度下降是在参数空间里走， 这里是在函数空间里走，走一步就多挂一棵树。

ν 控制每步走多远，和学习率是同一件事。演示里在异或数据上把 ν 从 0.1 调到 1.0，跑满 40 轮，训练 log 损失从 0.532 降到 0.267， 训练准确率从 82.7% 升到 91.4%。但这只说明它更贴合训练集，不说明它更好—— 实践里的标准做法是 ν 取 0.05 到 0.1，配上几百轮，再用验证集早停。

四、SVM 的间隔、hinge loss 与核。标签换成 y~​i​∈{−1,+1}。 如果两类能被 w⋅x+b=0 分开， 总可以缩放 w,b 使得离边界最近的点满足 y~​i​(w⋅xi​+b)=1。 此时两类之间那条带子的宽度是 2/∥w∥， 所以「间隔最大」等价于「∥w∥ 最小」：

真实数据一般分不开，硬约束会让问题无解。软间隔允许越界，但对越界量收费， 这个费用写出来就是 hinge loss：

hinge loss 有一个别的损失没有的性质：样本只要落在间隔之外 （y~​f≥1），罚项严格等于 0， 它对解没有任何贡献。所以最优解只由那些罚项非零、或恰好压在间隔线上的点决定， 这些点就是支持向量。线性可分数据配 C = 1 时，读数写着「支持向量 9 / 220」，意思是删掉另外 211 个点， 解一模一样。逻辑回归没有这个性质：远处的点也在贡献一点点梯度。

C 是在「间隔宽」和「分得对」之间的取舍。在线性可分数据上把 C 从 0.01 拨到 100，演示里间隔宽度从 5.36 收到 1.25， 支持向量从 155 个减到 3 个。

最后是核技巧。RBF 核的定义是

它凭什么等价于某个高维空间里的内积？把指数拆开就看得见：

每一项 (x⋅x′)k 都是「所有 k 次单项式组成的特征向量」 之间的内积。级数不截断，所以 RBF 对应的特征空间是无穷维的。 重点在于：这个无穷维向量从头到尾没被算出来过， 算法只需要 K(x,x′) 这一个标量，一次 exp 就够。 这就是核技巧（kernel trick）——把「映射到高维再做内积」换成「直接算内积」。

γ 决定每个样本的影响半径：核值降到 e−1 的距离是 1/γ​，再远就迅速掉到接近 0。 所以 γ 是影响半径平方的倒数，不是半径本身的倒数： 滑块从 0.05 拨到 2，半径从 4.5 缩到 0.7，缩了 6 倍而不是 40 倍。γ 调到 2 时，边界会退化成围着每个训练点画一个圈， 这是核方法最典型的过拟合形态。

还有一处实现细节值得说明：演示里的线性 SVM 先把两个特征标准化再做次梯度下降， 所以被最大化的是标准化坐标下的间隔，读数「间隔宽度」则换算回了原图的单位。 两个特征尺度接近时这两者几乎一致，双月数据上两轴标准差差了 1.6 倍， 解就会和「直接在原坐标上最大化间隔」略有出入。下面代码那段的 make_pipeline(StandardScaler(), SVC(...)) 是同一个做法。

标准化：树不需要，KNN 和 SVM 必须

决策树只比较「这个特征的值有没有超过阈值」，任何单调变换都不改变切分结果， 所以标准化对它完全没用。KNN 和 SVM 不一样：它们算的是欧氏距离。 如果一列是「年龄」（0–100）另一列是「年收入」（0–1000000）， 距离几乎完全由收入决定，年龄这一维等于不存在。 忘了加 StandardScaler 是这两个模型最常见的事故， 而且不报错，只是分数莫名其妙地低。

自己试试

  1. 1
    选「同心圆」+ SVM + 线性核，记下准确率；再切到 RBF 核。
    线性核停在 61.4%，RBF 核直接到 99.5%。切线性核时会跳出一条提示，说明这不是训练不够——线性 SVM 的假设空间里根本没有能分开同心圆的函数。
  2. 2
    选「螺旋」+ KNN，把 k 从 5 一路拉到 31，盯住读数里的「留一法准确率」。
    它会从 0.982 掉到 0.541。k 太大时，投票圈已经比螺旋的臂还宽，两条臂上的点混在同一个圈里投票，结构被平均掉了。这是 KNN 唯一的超参数，也是它唯一会调坏的地方。
  3. 3
    还在「螺旋」+ KNN、k = 31 的状态下，打开「按 1/距离 加权投票」。
    留一法准确率从 0.541 跳回 0.955，边界也从台阶变成连续过渡：31 个邻居还在投票，但近的那几个权重压倒性地大。同时训练准确率会变成 100% 并一直卡在那里——查询点落在训练点上时距离是 0，权重一百万，自己那一票必赢。这时候只有留一法还能用。
  4. 4
    选「螺旋」+ 决策树，maxDepth 从 1 拉到 6，然后在树结构图上点几个不同的节点。
    训练准确率从 58.2%（2 个叶子）涨到 80.5%（16 个叶子）。点节点时左边会高亮那个节点管的矩形，深度每加一层，矩形就被再切一半——但边界始终只有横线和竖线，斜着的螺旋只能靠阶梯硬凑。
  5. 5
    选「双月」+ 随机森林，把树的数量拉到 1，看那张缩略图；再拉回 24，看那一排六张。
    一棵树的袋外准确率是 83.8%，边界又糙又偏；24 棵树是 85.5%，大图明显平滑。六张缩略图彼此差得很远，这正是 bootstrap 加特征随机化想要的效果——树之间越不像，平均掉的误差越多。

    选「异或」+ 梯度提升，点「逐轮播放」看完 40 轮，再把学习率从默认的 0.3 依次改到 0.1 和 1.0 重播。
    第 0 轮整张图是均匀一片（只有常数初值 F₀），之后边界一块一块长出来。40 轮后的训练 log 损失：lr=0.1 是 0.532，lr=0.3 是 0.460，lr=1.0 是 0.267。lr=1.0 的边界明显更碎——它在拟合被噪声翻转过标签的那些点。
  7. 7
    数据集换成「类别不平衡」，随便挑一个算法看训练准确率。
    220 个样本里正类只有 15 个。一个把所有点都判成类别 0 的模型准确率就有 93.2%。KNN（k=9）的准确率是 95.5%，看起来更高，但它对正类的召回率只有 73.3%。这种数据上要看第 04 课的召回率和 ROC，不能看准确率。
